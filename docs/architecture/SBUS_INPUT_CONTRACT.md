## C1：协议与分层

- 第一版支持旧工程固定 profile：25 bytes；byte 0 为 `0x0f`，byte 24 为 `0x00`。
  不自动接受 SBUS2 或其他尾字节；实际接收机不匹配时先补证据、契约及向量。
- byte 1–22 按小端位流解出 16 个 11-bit 原始通道，范围 0–2047。
  byte 23 的 bit 0/1 为数字通道 17/18，bit 2 为 lost，bit 3 为 failsafe；
  保存完整原始 flags，未定义高四位不授予任何功能，不据此猜测新协议。
- 解析不包含 termios、FD、线程、时钟读取、通道用途或运动策略；实例单 owner。
  接受任意分块并有界缓存候选帧。坏尾字节报告 rejected 事件，保留候选内
  最早的后续头字节起始后缀继续匹配；不能丢弃可能形成下一帧的后缀。
- 每个完整帧／拒绝事件按顺序交给健康层；一次 read 含 lost 帧和健康帧时，
  不能只保存最后一帧而漏掉撤权。帧内 `0x0f` 不能提前截断候选。
- 不完整帧不发布；坏帧不刷新健康时间；结构有效的 flagged 帧仍发布原始观察，
  健康层立即失效。统计至少含收字节、完整帧、拒绝、丢弃、lost、failsafe。

## C2：UART、时间与会话

- Linux 候选串口格式为 100000 baud、8 data bits、even parity、2 stop bits；
  必须核验实际驱动设置／回读及物理解码。当前 SerialPort 无 100000 枚举，
  P9.2 在平台层补齐所需机制；不能回退成 115200 或把反相藏在协议解析里。
- 反相已由操作员确认完成，应用按可直接读取的信号接入，不再叠加反相。
  稳定设备路径、引脚／pinmux 及电气细节待记录；设备树和网络配置不属于实现。
  不支持速率、校验或必要配置时明确失败。PTY 不能证明电气、奇偶校验或真实速率。
- 完整帧使用同一 steady_clock 域的接收时间，绝不使用墙钟。多帧同一次读取可
  共享接收时间但有不同序号；处理／读取快照不能刷新该时间。
- UART 接收时间不是发射机采样时间。启动／重连清除解析残帧及历史输入，保持禁用；
  检测到积压、溢出或无法保证字节连续性时撤权并重新建立接收基线。P9.2 明确
  有界读取／积压处理及其可观测限制，不能将积压数据重新打戳作为新授权。
- 超时独立于帧标志，在无新字节时也必须执行。P9.3 规定
  `age >= timeout` 即失效；未来时间失效。初始离线兼容值为 100 ms。
  Linux 通用 `is_fresh` 是 `age <= timeout`；本节点不修改它，P9.3 在生产者
  明确处理等于边界。控制周期另行检查，P10 必须测试 owner 调度与失效传播上限。
- 启动／重新打开串口建立新的非零会话代际；同一进程内递增。每个新发布快照
  序号递增，读者可重复读相同快照但不得改变其时间、内容或代际。溢出则禁用，
  不循环复用旧标识。进程重启清除整个控制链历史，不恢复持久化授权。

## C3：映射与配置验证

下表通道角色已确认沿用，其余数值是旧行为的离线兼容 profile，不能直接启用实机运动。实际 profile
必须显式注入和验证，缺少校准时只允许原始值观察。

| 项目 | 兼容 profile | 验证规则 |
| --- | --- | --- |
| 通道（零起始） | 转向 0、油门 2、启停 5、档位 6 | 均在 0–15，四个角色不重叠 |
| 标定 | min=200、center=1000、max=1800 | 每个轴独立标定；0 ≤ min < center < max ≤ 2047 |
| 方向 | 转向、油门不反向 | 显式配置；逻辑方向不等于驱动对象符号 |
| 输入死区 | 50/1000 | 0 ≤ deadband < 1000，等于边界归零，外侧不重缩放 |
| 按钮 | raw ≤500 release，raw ≥1500 press | 0 ≤ release < press ≤2047；中间区保留按下状态，不产生边沿 |
| 档位 | raw ≤500 低，raw ≥1500 高，其余中 | 低阈值 < 高阈值，均在原始范围 |
| 档位 rpm | 30/60/100，全局 100 | 0 < low ≤ mid ≤ high ≤ global；运算用足够宽的中间类型 |
| 输出死区 | abs(rpm) <3 归零 | 非负且不超过全局上限 |
| 健康恢复／超时 | 3 个连续健康帧／100 ms | 恢复数 ≥1，timeout >0；计数饱和，不允许溢出恢复 |
| 按钮冷却 | 300 ms | 非负；等于边界允许下一次有效切换 |

归一化：raw ≤ min 为 -1000，raw ≥ max 为 +1000；区间内以 center 为零，
分别线性映射两侧，整数除法向零截断，再按配置反向及应用死区。
混控：`left = clamp(throttle + steering, -1000, 1000) * gear / 1000`；
`right = clamp(throttle - steering, -1000, 1000) * gear / 1000`，
再全局限幅及输出死区。校准端点是饱和点，不是帧有效性范围。

不搬用未验证的 expo、滤波、斜坡或增益公式。旧 pivot 开关为 OFF，
但直接混控在零油门／非零转向时仍会产生反向双轮请求；必须如实测试该公式，
不能声称已经禁止原地转向。任何此类物理动作均不在历史资格覆盖内。

## C4：健康、启停与授权

1. 启动为 disabled、invalid、零目标。连续健康帧只恢复信号健康，不自动启用。
2. lost、failsafe、拒绝帧、超时、UART 错误／断开／积压失连续性立即撤销
   输入有效性与启用，清零实际发布的两轴值，stop_requested=true，重置恢复计数
   和按钮 release 证据。保留原始原因，不能因后续健康帧消除撤权事实。
3. 恢复需配置数量的连续健康帧；新故障重置计数。启动时已按住按钮不算启用。
   恢复后必须在归一化油门和转向均处于输入死区时，以新的 release→press 边沿
   重新启用，且满足冷却。非中立按压不能排队等待自动启用。
4. 中立判定采用两个输入轴，不采用低速输出截断后的零 rpm：这是对旧代码
   candidate-rpm-zero 判定的明确收紧，防止非中立输入在输出死区内被错误 rearm。
   P9.3 必须为该差异先写边界测试。
5. 已启用时新的有效按钮边沿执行禁用；仍遵守兼容冷却。该按钮不是物理急停，
   lost/failsafe/超时的撤权不受按钮冷却限制。禁用后旧 press 不得自动恢复。
6. 每次合法启用产生新的非零输入 authorization_generation，并先发布零命令；
   它仅表示输入重新启用事件，不替代 SafetyManager 的系统授权和切源零保持。

## C5：命令快照与下游边界

- CommandSample 使用 source=sbus、实际接收 captured_at、新会话／序号、输入授权
  代际、valid/coherent/enabled/lost/failsafe。无效时两轴数值本身必须为零，
  不能只依赖 stop_requested 遮蔽残留目标。诊断保留候选值与原始帧，不能发送它们。
- 已启用的中立快照 valid/enabled=true，两轴为零；从未启用或失效时 valid/enabled=false。
  通信健康与命令有效分开，不添加第二套驱动安全状态机。
- 单一生产者按值发布不可变快照；读者不能看到混合帧、半更新代际或未初始化字段。
  输入模块不持有 CAN、SDO、控制字或驱动写权限。
- 现有 arbiter 允许重读相同 sequence，拒绝更小 sequence；生产者禁止同序号改内容。
  不为输入节点顺带重构仲裁。
- 已发现 P10 接口衔接项：现有 arbiter 在 SBUS 为零、外部缺席时返回无效 selection，
  尚需明确纯 SBUS 中立重新授权如何传给 SafetyManager；另需把输入 rearm 事件
  映射到系统授权代际。不能伪造外部命令绕过；P10 先加整链测试再作必要修改。
